# Bootstrap_EGE_Test

Учебный веб-тест по информатике на HTML, CSS, Bootstrap 5 и JavaScript.

## Файлы
- `index.html` — структура страницы и подключение Bootstrap через CDN.
- `style.css` — дополнительные стили.
- `script.js` — проверка ответов, массивы, цикл, события и LocalStorage.

## Запуск
Откройте `index.html` в браузере. Для загрузки Bootstrap требуется подключение к интернету.

## Проверка
1. Введите ответы `60`, `10`, `1024` и нажмите «Проверить ответы».
2. Введите ответы и нажмите «Сохранить ответы».
3. Перезагрузите страницу и нажмите «Загрузить сохранённые».
4. Нажмите «Очистить», чтобы сбросить поля.

## Публикация через GitHub Pages
1. Отправьте файлы проекта в репозиторий GitHub.
2. Откройте Settings → Pages.
3. В разделе Build and deployment выберите Deploy from a branch.
4. Выберите ветку `main` и папку `/ (root)`, затем нажмите Save.
5. Дождитесь публикации и откройте ссылку, которую покажет GitHub Pages.

Ответы сохраняются только в LocalStorage конкретного браузера и устройства. Они не отправляются на сервер.
